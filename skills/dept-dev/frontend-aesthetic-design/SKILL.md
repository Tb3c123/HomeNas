# Frontend Aesthetic Design

## Use This Skill When
- Designing landing pages, web apps, dashboards, or interactive tools from scratch.
- Elevating a functional prototype into a clean, cohesive, production-grade UI.
- Auditing visual clutter, weak hierarchy, or generic template aesthetics.

## Core Principles
1. **Intentional Direction First:** Before writing CSS, commit to one clear aesthetic direction (e.g., Swiss editorial, tactile minimalism, precision scientific tool, warm studio) aligned with the product domain.
2. **Eliminate "AI Slop":**
   - Avoid default purple-on-white SaaS gradients, excessive glassmorphism, meaningless glowing orbs, and decorative badge soup.
   - Prefer crisp borders, restrained accents, generous whitespace, and purposeful alignment.
3. **One Focal Point Per Viewport:** Establish a clear 3-level visual hierarchy (primary hero/action, secondary context, tertiary metadata) using size, weight, contrast, and spacing—not just boxes around everything.
4. **Restrained Palette (60-30-10):** Reserve saturated accent colors strictly for primary CTAs, active indicators, and semantic status; keep 90% of surfaces calm and neutral.
5. **Real Visual Rhythm:** Use consistent 4px/8px spacing multiples, align baselines across adjacent columns, and let content breathe instead of nesting cards inside cards.

## Delivery Checklist
- Define aesthetic direction, surface hierarchy, and primary focal action before coding.
- Verify no redundant borders, nested card clutter, or competing primary buttons exist on the same screen.
- Check visual balance in both desktop and mobile viewports with realistic content (not just short placeholder labels).
